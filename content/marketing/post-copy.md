# Ready-to-use post copy

## Speaklet

I built Speaklet, a tiny dictation app for the Mac.

Hold Fn, speak, and release. Your words go into the field you’re writing in where supported. The small dark capsule expands while you talk. Terminals and compatible editors use guarded clipboard paste, and there’s a copy fallback when insertion isn’t available.

It’s native Swift, free, and open source under Apache 2.0. You’ll need macOS 13+ and your own OpenAI API key; API usage is billed separately from ChatGPT subscriptions.

Download and setup: https://dhayanandbaskar.github.io/apps/speaklet/
Source: https://github.com/DhayanandBaskar/speaklet

## Still

I built Still for the part after writing: reading.

Open a Markdown file, follow its heading outline, or switch to focus mode and settle into the text. Choose light, dark, or system appearance, and adjust the type to suit you. Still stays read-only while your editor does the writing.

This is a personal Mac build, currently for Apple silicon. Details and a build on request: https://dhayanandbaskar.github.io/apps/still/
