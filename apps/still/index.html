01 / Get started

From file to focused reading.

  1. Open your Markdown

    Press ⌘ + O, drag a .md or .markdown file onto Still, or use Finder’s Open With. The personal build is not notarized; macOS may require Open Anyway in Privacy & Security.

  2. Navigate the outline

    Use the nested heading index to jump between sections. Collapse branches or resize the sidebar. Recent files appear below the outline.

  3. Settle into the text

    Choose Light, Dark, or System appearance, adjust the font and text size, or press ⇧ + ⌘ + F for focus mode.

  4. Keep reading as files change

    Still reloads when the file changes on disk. Use ⌘ + R to refresh manually. Edit in your preferred editor; Still remains read-only.

03 / What it reads

Markdown, comfortably.

The usual Markdown

Headings, lists, read-only checkboxes, quotes, links, tables, code blocks, strikethrough, images, and sanitized HTML.

Know the boundaries

UTF-8 and UTF-16 files up to 25 MB. Math, Mermaid diagrams, and syntax highlighting are not supported. Remote images load from their original hosts.
