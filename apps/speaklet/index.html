01 / What it does

Your words, in your workflow.

01

Speak from the keyboard

Hold Fn/Globe and release to transcribe. Prefer a shortcut? Use Control + Option + Space, or click the capsule to start and stop.

02

Keep your place

Speaklet attempts insertion in the original text field. If you change focus or move the cursor, it keeps the transcript available to copy instead.

03

Paste into terminals

Guarded clipboard paste supports terminals and compatible editors. Terminal text stays on one line; Speaklet does not press Return or submit a command.

02 / Get started

From install to first dictation.

Have your OpenAI API key ready before you start.

  1. Install one copy

    Open the DMG, drag Speaklet.app into Applications, and launch that copy. This personal build is locally signed and is not notarized. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway for Speaklet.

  2. Add your API key

    Open Settings from the menu-bar icon or the capsule’s right-click menu. Save your OpenAI API key ↗. Enable API billing in your OpenAI account. The key is kept in macOS Keychain.

  3. Grant the Mac permissions

    Use the app’s guidance to allow Microphone for recording, Accessibility for insertion, and Input Monitoring for the global hold shortcut. Enable the Applications copy and reopen it if macOS requests it. Permission status updates automatically.

  4. Focus a field and speak

    Place the cursor in the field you want to fill. Hold Fn / Globe, speak, then release. Or hold Control + Option + Space. Click the capsule if you prefer using the mouse. Wait for transcription before moving the cursor.

  5. Check the result

    The transcript appears in the original field where supported. If insertion is unavailable, copy it from Latest Transcript. To check insertion without recording or API usage, focus a disposable text field and choose Test Text Insertion from the right-click menu.

03 / Everyday controls

A few useful things to know.

Cancel with Escape

Press Esc to cancel recording or a pending request. A recording stops after two minutes.

Choose your shortcut

If Fn opens emoji or Apple Dictation, change its macOS Keyboard action to Do Nothing, or use Speaklet’s alternative shortcut.

Make it comfortable

Settings lets you change the capsule’s position and idle darkness. The control respects Reduce Motion and Reduce Transparency.

Use the clipboard when needed

Enable Use clipboard paste for terminals and compatible editors. Speaklet restores your previous clipboard after a paste unless you’ve copied something new.

04 / Before you download

Straight answers.

Does my ChatGPT Pro subscription cover Speaklet?

Speaklet currently uses an OpenAI API key. Its API usage is billed separately from your ChatGPT subscription. The app itself is free. See OpenAI’s billing explanation ↗.

Where does the audio go?

After you stop recording, Speaklet sends the audio over HTTPS to OpenAI for transcription. The default is gpt-4o-mini-transcribe; Settings also offers gpt-4o-transcribe and whisper-1. Local temporary audio is deleted after completion or cancellation. Transcripts stay in memory until cleared or the app quits. An upload already sent cannot be recalled.

Why does it sometimes show a transcript window?

The original field may have changed, focus or the cursor may have moved, or the app may not support automatic insertion. Speaklet keeps the result available to copy and shows the reason above it. Password fields are excluded where detectable. Use Test Text Insertion to check a field without spending API credits.

Why can permissions look enabled but not work?

macOS can retain approval for an older app identity. Keep one Applications copy. If migrating from an old Whisper Bubble or ad-hoc build, replace only that app’s stale Accessibility and Input Monitoring entries with the installed Speaklet copy, then reopen it. Current releases reuse a persistent signing identity to preserve approvals across updates.

Can I inspect, change, or build it?

Yes. Speaklet’s source is public under Apache 2.0. The repository includes build instructions, validation notes, and source for the native Swift app. Browse the code ↗.
