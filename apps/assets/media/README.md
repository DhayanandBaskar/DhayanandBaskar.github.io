# Speaklet + Still media kit — feature series

Ten App Store-style feature illustrations: five for Speaklet and five for Still. Each PNG is 1536 × 1024. Made with built-in image generation from actual app screenshots and the production Speaklet control.

## Speaklet — five illustrations

1. `illustrations/speaklet-01-dictate.png` — Hold a key. Say it. Keep going.
2. `illustrations/speaklet-02-shortcut.png` — Hold. Speak. Release.
3. `illustrations/speaklet-03-capsule.png` — Small until you need it.
4. `illustrations/speaklet-04-insertion.png` — Keep your place.
5. `illustrations/speaklet-05-personalize.png` — Make it yours.

## Still — five illustrations

1. `illustrations/still-01-reader.png` — Open the file. Find your place.
2. `illustrations/still-02-outline.png` — Find your section.
3. `illustrations/still-03-focus.png` — Let the page take over.
4. `illustrations/still-04-typography.png` — Read it your way.
5. `illustrations/still-05-workflow.png` — Write elsewhere. Read here.

The artwork uses enlarged interface details, large feature headlines, cobalt, ivory and graphite. These are illustrations, not raw screenshots; they crop, simplify and restyle the interface. Some article body text is illustrative. Use the original screenshots to show the exact app.

## Actual screenshots and references

- `screenshots/speaklet-settings.jpg` and `speaklet-controls.jpg` — unchanged native captures, 1140 × 1384. Installed Speaklet 1.0.6, API key field empty.
- `screenshots/still-reader.jpg`, `still-focus.jpg`, `still-dark.jpg` and `still-dark-serif.jpg` — unchanged native captures, 3024 × 1774. Still’s bundled public Welcome.md; recent filenames hidden.
- `references/speaklet-idle.png` — native production idle control export.
- `references/bubble-preview-poster.png` — 1280 × 560 production recording control, enlarged with sample microphone levels.
- `speaklet-icon.png` and `still-icon.png` — actual app icons.
- `app-store-prompts.json` — prompts, reference paths, refinements and generated image IDs.
- `post-copy.md` — launch and feature copy for your own posts.

Captured on 11 October 2026. No private documents, API credentials or dictated transcripts are included. Original captures can show the pointer or macOS capture overlays; these are removed in the illustrations.
