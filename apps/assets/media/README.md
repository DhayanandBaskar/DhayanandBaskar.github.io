# Speaklet + Still media kit

Two native Mac apps by Dhayanand Baskar. Captured on 11 October 2026.

## Use these images

- `illustrations/speaklet-illustration.png` — 1536 × 1024, screenshot-based product illustration.
- `illustrations/still-illustration.png` — 1536 × 1024, screenshot-based product illustration.
- `screenshots/speaklet-settings.jpg` and `speaklet-controls.jpg` — unchanged native captures, 1140 × 1384.
- `screenshots/still-reader.jpg` and `still-focus.jpg` — unchanged native captures, 3024 × 1774.
- `references/speaklet-capsule.jpg` — original small capsule reference, 224 × 104. The captured pointer obscures part of it; use the illustration or other screenshots for posts.
- `prompts.json` — exact prompts and reference paths used with built-in image generation.
- `post-copy.md` — copy you can paste into your own posts.

The illustrations come from real screenshots. They simplify and restyle the interface, so label them as illustrations when appropriate. The native screenshots are unchanged; macOS capture overlays and the pointer can be visible. Speaklet Settings was captured from the installed 1.0.6 build with the API key field empty. Still displays its own bundled Welcome.md, with recent filenames hidden. No private documents, API key values, or dictated transcripts are included.
